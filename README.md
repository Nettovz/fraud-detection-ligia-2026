# fraud-detection-ligia-2026
Solução de detecção de fraudes em transações financeiras desenvolvida para o processo seletivo da LIGIA (UFPE). O projeto aborda um problema de classificação binária com forte desbalanceamento, utilizando Regressão Logística e LightGBM, com foco em ROC-AUC, ajuste de threshold e interpretabilidade do modelo.
